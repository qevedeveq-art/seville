# Séville · 30 sept – 3 oct 2026

Guide de voyage perso (site statique GitHub Pages) : programme jour par jour, carte interactive, adresses aimées des Sévillans, infos pratiques.

- `index.html` — la page
- `data.js` — **tout le contenu** (lieux, programme, check-list). Pour ajouter un lieu : copier un bloc dans `PLACES` avec un `id` unique, une catégorie et des coordonnées (clic droit dans Google Maps → copier les coordonnées).
- `app.js` / `style.css` — rendu et carte (Leaflet + OpenStreetMap)

Publication : Settings → Pages → Source « Deploy from a branch » → `main` / `(root)`.
